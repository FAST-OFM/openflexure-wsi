# Security policy

This software is a research prototype and is not clinically validated. Report
sensitive vulnerabilities privately through GitHub Security Advisories. Do not
attach credentials, private network details, patient data, or unpublished
specimen images.

State the affected release tag and feature ID, whether the issue can cause
motion, illumination, capture, data exposure, or resource-exhaustion effects,
and provide a minimal sanitized reproduction. The maintained prototype line is
`v0.2.0-prototype.*`.
