OpenFlexure Microscope HTTP API

These docs are provided for reference only. They cannot control a running microscope.

For interactive documentation on a live microscope, visit:
http://microscope.local:5000/docs

You can also directly inspect the OpenAPI JSON file openapi.json or the WC3 "Web of Things" Thing Descriptions JSON thing_descriptions.json

Replace microscope.local with your microscope's hostname or IP address if your network uses a different name.
