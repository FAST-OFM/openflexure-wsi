# Upstream provenance

This repository is an independent modified distribution of the OpenFlexure
Microscope Server. It is not an official OpenFlexure release and does not imply
endorsement by the OpenFlexure project.

## Source baseline

- Upstream project: OpenFlexure Microscope Server
- Upstream repository:
  <https://gitlab.com/openflexure/openflexure-microscope-server>
- Upstream branch: `v3`
- Base commit: `4aa9ef70403b5e6fd9cd71712f937700947c2609`
- Base tree: `25ecf734e2841dd02c802354184342ef05e23d1d`
- Fast OFM engineering snapshot:
  `a4231aa2538c0c67f306a666011abfd0de68d1db`
- Snapshot tree: `9f0672f29ed67448d13e0b29c8e0c5e71d40b1ab`

The clean Fast OFM repository intentionally does not import the private
development commit history. The immutable identifiers above permit comparison
with the original source. `MODIFICATIONS.md` describes the grouped changes.
